# Android Basics with Compose

I created this repository to learn Android app development with Kotlin and Jetpack Compose. The projects in each folder are based on the tutorials and codelabs from the corresponding unit of the [Android Basics with Compose course](https://developer.android.com/courses/android-basics-compose/course).

## Course units in this repository

- [Unit 1](Unit%201/) covers Kotlin fundamentals and building a first Android app.
- [Unit 2](Unit%202/) introduces interactive Compose layouts and UI state.
- [Unit 3](Unit%203/) covers scrollable lists and Material Design.
- [Unit 4](Unit%204/) introduces navigation and app architecture.
